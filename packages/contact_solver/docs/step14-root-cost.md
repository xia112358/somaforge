# 第14帧：提高 root 修正代价

在真实网络输出上增加标量修正代价，root 平移和旋转的归一化单自由度代价分别取关节的 1、100、1000 倍。
参考姿态是本次网络更新前的原始预测，固定并 detach；不是上一帧，也不是 QP 解。

令平移尺度为 0.02m，角度尺度为 0.1rad：

```
L_correction = 0.5 * (
  root_weight * (sum((delta_root_xyz / 0.02)^2) + rotation_cost)
  + sum((delta_joint / 0.1)^2)
)
rotation_cost = 4 * ||normalized_quat - sign * reference_quat||² / 0.1²
```

四元数符号按最短等价表示对齐；旋转使用弦距离，在小角度下等价于旋转角平方。
代价相较的是归一化位移，不能直接比较米和弧度。root 未冻结。
总损失为原 SDF 求和项、Newton 自碰撞局部代理、原接触保持项和新修正代价；替换原微弱姿态正则。
此实验不使用之前的相对高度辅助项。

## 真实网络验证

每组重载同一个 checkpoint，普通参数梯度下降40步；所有接受的步长均为1e-9。
入口实现了基于新 Newton 查询的 Armijo 回溯，但本次120步均第一次试探通过，没有缩步。
不是直接优化姿态、不是 QP，也没有输出投影或梯度预条件。

| root/关节代价比 | root平移 cm | root旋转 ° | 最大关节变化 ° | 足部全网格嵌入 cm | 原接触保持 |
|---|---:|---:|---:|---:|---|
| 1 | 3.44856 | 0.34135 | 0.33386 | 5.20000 | 是 |
| 100 | 2.11423 | 0.36503 | 0.48358 | 6.44130 | 是 |
| 1000 | 0.75770 | 0.61935 | 1.09160 | 7.42797 | 是 |

提高 root 代价减少了平移，并增加了关节修正，但旋转没有单调减小。
这是固定40步的行为对照，不是各权重已收敛最优解的比较。
全足网格初始嵌入约8.9981cm，所有组仍未通过静态恢复验收。
Newton 最大负距离三组分别为5.12690、4.49825、4.00988cm，原始约2.65637cm；
因此不能把总损失下降或全足网格改善解释成所有碰撞指标都改善。
总损失包含采样和局部 witness 代理，不保证新出现点对的最大负距离单调改善。

所有更新保持原计划 contact/cell 不变；所有终态保留原左手/左膝真实接触，无关节越限。
这里只验证限制 root 的效果，没有实现完整接触恢复。未改写 checkpoint 或生产训练配置。

平方代价在参考点的梯度为零，各组第一步相同；后续位移才产生回拉梯度。
本次没有通过自定义 backward 伪造第一步的 root 优先级。
网络重放误差与上一轮相同，具体记录在 diagnostic.json 中。
所有接触采用原 Newton 实际激活/分配及真实水平主表面筛选，不以几何深度定义接触。
