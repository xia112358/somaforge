# 通用约束驱动学习

目标是让网络直接面对几何和接触约束，训练链路不求解QP，也不读取QP修正姿态。这里提供可复用的残差和损失层，不绑定机器人部位、场景高度或某一帧。

## 分层接口

1. **机器人/场景适配器**提供可微FK、形状支撑间隙、采样点、环境距离、自碰撞距离和真实关节限位。模块不猜测缺失几何；当前G1研究适配器继续使用权威资产和现有Newton查询。
2. **任务描述**通过 `ContactTask` 指定建立/保持/释放、间隙区间和尺度。表面坐标、朝向目标、覆盖点、材料点保持均外部传入；球形手或膝没有默认足底法线。
3. **残差层**输出 `Residual`：样本ID、上下文版本、约束ID、稳定分量ID、等式/不等式类型、归一化值及有效性。
4. **损失层**对同一批残差构造固定罚项或Augmented Lagrangian。梯度直接经过残差与FK进入预测网络。
5. **验证层**独立检查Newton实际接触激活、约束分配和主表面。几何残差不能定义接触真值。

`constraint_residuals.py` 提供平面/凸多边形区域接触、关节限位、环境和自碰撞有符号距离封装，以及可配置姿态正则。
环境查询接口 `SignedDistanceField.distance(points)` 可接其他后端；内置解析平面、定向盒和球。
这些接口不等于已经实现任意非凸网格SDF、所有机器人资产解析或GPU批量FK；这些能力由具体适配器提供。

`pose_coordinates.py` 提供浮动基座XYZ/WXYZ/关节的固定归一化切空间；尺度由调用方指定，SO(3)最短log在pi附近存在分支，不保证全局光滑。

## 约束语义

- 等式：`c == 0`；不等式：`g <= 0`。无穿透保留 `g = clearance - distance` 的符号，不先截断。
- 新建/保持接触：支撑间隙上下界；按任务选择切向材料点保持、法线方向和区域覆盖。法向区间由调用方根据实际求解器字段配置，不内置接触阈值。
- 朝向残差使用单位法线向量之差，反向法线不会像叉积残差一样错误地得到零。
- 释放只要求指定的最小分离距离，不附加锁定或朝向目标。
- 穿透约束允许环境和自碰撞独立标识。形状采样覆盖只是近似；缺失Newton点对不能据此宣称无自碰撞。
- 保持接触的锚点必须来自外部有效状态，并在该任务版本内固定，不能跟着预测漂移。
- 预测接触意图与实际接触分开。当前任务有效接触依然共用core的水平真实主表面筛选；通用平面数学接口不改变任务接触判定规则。
- `quadratic_prior` 只计算调用方提供的位姿差及权重。相对原预测的偏移是修正正则，不冒充自然姿态先验。

## 固定罚项与AL

固定罚项：`L_prior + rho/2 * (sum(c²) + sum(relu(g)²))`。

AL：

```
equality:   lambda*c + rho/2*c²
inequality: (relu(lambda + rho*g)² - lambda²) / (2*rho)
```

等式乘子无符号约束；不等式更新 `lambda = relu(lambda + rho*g)`。满足并有余量的约束可以降低乘子。
每一组primal步骤后才显式调用 `update(fresh_residuals)`，不是每次forward修改状态。
可按约束违反的改善情况增大rho，有上限；rho是每个残差块的状态，分量乘子各自独立。
跨dual更新的AL数值不能直接当作同一个固定loss的收敛曲线，应比较真实约束指标。

### 状态与batch

键为 `(sample_id, context_id, constraint_id, component_id)`。batch顺序不影响状态。
上下文必须反映机器人/场景版本、任务目标、锚点、尺度和采样定义；修改这些定义需新上下文或显式reset。
动态碰撞使用稳定形状/点对ID，禁止把当前查询行号当物理身份。消失的分量保留状态，重新出现时按ID恢复；任务结束后调用reset回收状态。
研究适配器将自碰撞按shape-pair聚合最小距离，避免点对数量改变导致行号串用。

空的已知候选集由适配器负责说明；未知/无效/非有限残差明确报错，不跳过、不当作零。
重复ID、类型在同一上下文中改变均报错。更新先验证全部输入，避免失败时部分更新乘子。
支持 `state_dict` / `load_state_dict` 保存与恢复，恢复时验证配置和状态。

## 实际接入示意

```python
from contact_solver import AugmentedLagrangian

al = AugmentedLagrangian(rho=1.0)
# adapter由调用方提供，负责固定任务上下文和真实几何。
q_pred = model(batch)
prior, residuals = adapter.evaluate(q_pred, batch)
loss = al.loss(prior, residuals)
loss.backward()
optimizer.step()
# 每个外层周期结束，重新前向/查询后：
al.update(fresh_residuals)
```

当前没有修改正式训练入口或默认训练损失。上述接口可供训练使用，但物理恢复效果仍需评估。

## 首轮真实网络实验

外部配置：`configs/contact_learning/step14_static.json`。其中的部位名称和箱顶选择只属于测试任务，未写入通用损失模块。
配置包含新建足部接触、保持手/膝接触、全身环境采样穿透、地面支撑、自碰撞及关节限位。
指定足部朝向和覆盖任务，与此前QP教师实验的优化目标不完全相同，不能直接比较收敛速度。
root归一化代价为关节的1000倍，整体prior权重0.001；距离尺度0.01m，角度尺度0.1rad，不是实际接触判定阈值。

同一checkpoint分别进行原输入、输入root X偏移1cm、输入左髋pitch偏移0.02rad三个独立案例。
每个案例重载网络，固定罚项与AL各120步，AL每10步更新乘子。真实网络参数更新，接受前重新查询Newton。
这是三个单样本局部适配实验，不是一个共享模型的多样本训练，也不构成泛化证明。

| 输入案例 | 方法 | 足部完整网格嵌入 cm | root相对本案例初始预测位移 cm | 原接触全部保留 | 静态验收 |

| 原输入 | 固定罚项 | 3.926 | 4.444 | 否 | 未通过 |
| 原输入 | AL | 1.306 | 5.949 | 否 | 未通过 |
| root X +1cm | 固定罚项 | 4.805 | 6.167 | 否 | 未通过 |

| 左髋pitch +0.02rad | AL | 1.726 | 5.231 | 否 | 未通过 |

AL在这组预算内减少了更多足部嵌入，但仍丢失已有接触。原输入AL第60步曾出现零穿透，同时已有接触失败，不计为成功。
所有组均跑满120步，计划contact/cell保持不变。本轮没有非法Newton法线试探。
结论仅是通用接口与训练链路可运行，不能宣称已经学会whole-body contact resolution。
失败原因尚未完全隔离，可能涉及有限primal更新、残差尺度、目标可行性及几何指导与真实接触的差异，不指定单一根因。
