# 第14帧：损失梯度与真实网络单步验证

本轮没有使用 QP、接触度量预条件、梯度裁剪、动量或自适应步长。每个试探独立从同一姿态/网络参数开始。
姿态探针使用固定坐标尺度（平移0.02m，角度0.1rad）；网络探针对实际有梯度的参数执行普通SGD，重新前向。
checkpoint 未改写，没有停止或启动训练任务。

## 结论

当前损失未达到“下降即可产生合理接触修正”的要求。一次真实网络更新已经构成反例：
SDF求和+接触保持+姿态偏移总损失由616.455降到477.933，足部完整网格嵌入由8.9973cm降到2.7801cm，
但root位移5.7320cm且原接触丢失。规划的contact/cell没有变化，变化来自执行网络参数更新后的姿态输出。
所有探针均未通过完整静态恢复验收。

| 网络SGD学习率 | 总损失前→后 | 足部全网格嵌入 cm | root位移 cm | 原接触全部保留 |
|---|---|---:|---:|---|
| 1e-9 | 616.455→387.979 | 8.37580 | 0.57368 | 是 |
| 1e-8 | 616.455→477.933 | 2.78007 | 5.73203 | 否 |
| 1e-7 | 616.455→286094.413 | 0 | 57.24305 | 否 |

最大步长不满足总损失下降，仅作失败探针，不能当作成功结果。
root位移按原保存姿态计；网络自身重放root差异仅0.001627cm。

## 梯度分项

所有非零分项的35维中心差分相对L2误差小于6.6e-10（冻结Newton witness的局部代理）。
固定尺度下，负梯度产生的root竖直变化率：SDF项2.35860、接触保持项14.48139、姿态项0。
这里是每单位无量纲步长的米数，不是每秒速度。保持项约为SDF的6.14倍。

保持项并非初始恒零：它同时要求原接触link的整个collision支撑脱离穿透，初始最大法向残差2.6773cm。
所以它也在强烈推动整体向上，不能把所有root漂移归因于SDF。原材料点XY初始几乎不动，主要初始驱动来自法向项。
姿态平方偏移在起点严格为零梯度，因此提高其权重不能改变第一步方向，只能影响后续步。

附加相对支撑高度损失使用左脚最低支撑与原手/膝支撑的高度差，根平移对该项完全抵消；
但与原总损失相加后，1e-8网络探针仍丢接触、root移动5.73245cm。不能据此宣称已解决。
该辅助项也不构成完整足底姿态/目标接触定义。

## 语义与范围

原预测意图是双脚+左手，坏姿态实际接触是左手+左膝。本轮只验证左脚恢复并保留初始真实接触，
不证明整个预测计划实现。目标顶面距离只作分项方向诊断，没有直接加入两个总损失版本。
Newton实际激活、约束分配及真实水平主表面筛选定义接触；几何深度不定义接触。
每个姿态保存同帧、无积分原始查询字段，独立全足网格检查不使用训练采样点。

网络输入使用重新查询的接触和真实mesh重建heightmap。重放不是逐位一致：最大分量差6.7592e-5，
根位置差1.6268e-5m，最大关节差6.7592e-5rad。明确记录并独立查询network_baseline；网络损失前值来自自身未更新输出。
首次运行暴露Float/Double输入错误，第二次严格2e-5重放门限失败；两次均保留日志，未声称完成网络实验。
第三次使用显式1e-4数值重放门限完成。两项RecoveryGeometry测试通过。

下一步应重构明确的接触目标与保持损失，并继续以真实网络更新后的接触/穿透/root指标验收。
目前没有可宣称替代QP效果的训练损失，不能仅按总loss降低挑选成功样本。
