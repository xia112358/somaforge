# 候选步可行性筛选

第一阶段只改变候选步接受规则，不改变AL残差、梯度生成、乘子更新周期或姿态正则。第二阶段在检测到停滞后，额外更新阻塞约束的AL乘子。两阶段均不使用QP目标、梯度投影或推理后处理。

## 通用接口

`FeasibilityFilter` 接收外部配置的 `ProtectionRule(prefix, tolerance)`，不识别特定机器人、部位或地形。
输入为当前/候选的同一套 `Residual`，以及独立的实际证据字典。

- 每个受保护分量分别检查，不能用一个约束改善抵消另一个约束恶化。
- 当前违反量不超过容差时，候选也不得超过容差。
- 当前已违反时，候选违反量不得增大；后续用已接受姿态作为新基准，逐步收紧。
- 新出现的受保护违反量超过容差则拒绝。
- 之前存在的保护残差缺失时记为未知并拒绝，不能静默视为满足。实际后端若能证明不再适用，应由适配器显式处理任务上下文。
- 需要保留的实际接触必须由Newton证据继续确认；几何残差不能替代这个证据。

筛选本身不生成新方向，只接受/拒绝。优化器仍需通过缩步寻找既降低目标又满足保护规则的候选。
原始目标下降规则和筛选要同时通过；没有可接受步则恢复参数并记录 `no_acceptable_step`，不放宽规则冒充成功。

## 测试任务配置

外部配置 `configs/contact_learning/step14_filter.json` 使用第14帧原输入。
保持接触的归一化容差0.05，对应0.5mm；碰撞恢复的允许容差0.02，对应0.2mm；关节限位归一化容差1e-5，对应1e-6rad。
这些是优化保护容差，不是接触判定阈值。实际接触仍使用当前Newton CONSTRAINT/includemargin/约束分配及主表面筛选。

两个分支均使用原AL目标、相同的网络初始化、初始试探学习率1e-7、24级回溯，每10个接受步更新乘子，预算240步。
`armijo_only` 只要求实际目标下降；`protected` 额外要求上述逐分量保护和原接触保留。

## 数值一致性修复

第一版记录暴露了一个真实问题：带梯度前向与no_grad推理前向使用不同MHA执行路径，出现微小输出差异。
旧回溯把autograd前向的loss与候选推理loss直接比较，极小学习率时可能把执行路径差异算作进展。

第二版显式关闭本实验进程的MHA推理fast path，并记录开关前后同参数的前向差异。
回溯基准改为当前已接受**实际姿态**的loss，要求严格下降；不依赖autograd前向数值充当实际基准。
这项控制同时应用于两个分支。未修改正式训练默认设置，也未把数值容差用于放宽实际接触规则。

`v1` 产物保留审计，正式对照以 `tmp/feasibility_filter_20260926_v2/` 为准。

## 边界

这是一个约束保护机制，不保证存在满足筛选的下降方向，也不保证能解除深嵌入。
逐项单调恢复可能排除需要暂时增加某项违反量的路径。缺失保护残差的保守处理也可能导致停滞。
接触和碰撞采样仍受适配器覆盖限制，不能据此证明连续轨迹安全或动力学可执行。

复现：沿用原Newton worker参数，设置 `CONSTRAINT_LEARNING=1`、`FEASIBILITY_FILTER_EXPERIMENT=1`、
`CONSTRAINT_CASE_CONFIG=configs/contact_learning/step14_filter.json` 和新的 `STEP14_FIELD_OUTPUT`。
入口仍为 `python -m contact_solver.research.step14_loss_direction`。

## 停滞时更新阻塞约束乘子

仅筛选无法产生新方向。第二阶段 `protected_dual_restore` 在一次完整回溯找不到候选时：

1. 恢复原网络参数。
2. 从本次回溯中选择最小的、有实际位移且降低目标、但被筛选拒绝的试探。
3. 提取其中恶化的保护残差身份，用**当前已接受姿态**的残差更新这些约束的AL乘子和rho。
4. 重新计算原AL公式的梯度，重新试探。容差、锚点和接触规则不变。

这会改变后续梯度，是在第一阶段单变量对照之后增加的第二项实验，不混称为仅改变接受规则。
如果只有实际证据失效而无法定位到残差，或连续12次阻塞更新仍无可接受步，则明确停止。
例行dual更新仍每10个接受步触发。恢复更新本身不计为网络参数更新，不把拒绝姿态作为teacher。

## 结果

| 方法 | 接受的网络步 | 额外阻塞dual更新 | 足部嵌入 cm | root位移 cm | 原接触全程保留 | 关节越限 | 终止 |
|---|---:|---:|---:|---:|---|---|---|
| 仅目标回溯 | 240 | 0 | 0.22684 | 5.45393 | 否 | 无 | 预算上限 |
| 回溯＋保护筛选 | 5 | 0 | 8.46538 | 0.47293 | 是 | 无 | 无可接受步 |
| 再加阻塞dual更新 | 31 | 28 | 5.00816 | 3.57122 | 是 | 无 | 无可接受步 |

三组均未通过完整静态验收。不能因第三组保持了接触就宣称已经解决足部嵌入。
第三组最大关节调整仅0.40319°，仍主要依赖root移动；尚未产生充分的腿部协同。
第三组终态最大材料点切向漂移0.04025cm，原左手/左膝接触保持，并出现左脚激活接触，但足部仍穿透约5cm。
接触激活绝不等于无穿透或合理承重。第三组Newton最大负距离约4.93144cm，也不是合格恢复。

第二版前向一致性审计：关闭MHA推理fast path前最大差异4.4346e-5，关闭后为0。
基础筛选在第6次尝试中：23个有位移且降低目标的候选被保护拒绝；最后一个候选无位移、无下降。
主要阻塞是左手切向分量到达0.5mm优化容差。不是单纯把学习率再缩小就能取得有效进展。

额外阻塞dual更新共28次，跨多个停滞位置；最终连续12次停滞更新集中在左手法向上界，仍找不到可接受步。
它让优化离开了第一次切向阻塞，但没有完成全身协调。这里仅证明有限预算、指定候选方向上的停滞，不能证明附近不存在可行方向。
