# 第14帧：固定 QP 梯度教师

目的：区分几何损失给出的关节修正方向与网络参数更新造成的输出耦合。QP 只提供固定、停止梯度的研究目标；不是推理 projector。

## 方法

使用旧实验 `face3_iter5` 的 QP 姿态，先在当前 Newton 模型重新查询并确认静态验收通过。
网络初始输出为参考姿态，统一35维坐标：世界平移 / 0.02m、相对 root 旋转向量 / 0.1rad、关节变化 / 0.1rad。
root旋转用 SO(3) log/exp，四元数符号对齐，不直接相减。固定切空间中的教师损失为 `0.5 * ||z - z_target||²`。
起点负梯度严格等于教师方向，已数值检查。这个等式成立于所声明的归一化坐标，不宣称原始36维四元数坐标拥有相同欧氏梯度。

- 直接姿态SGD：每步0.5，每步教师误差减半，共8步。
- 网络SGD：仅教师损失，真实更新参数并重新前向，300步；有Armijo回溯，本次所有步长均为1e-6。
- 小步网络方向：学习率1e-9，分别使用教师损失和SDF环境项；两种网络向量明确区分。
- 等幅探针：统一归一化步长为完整QP方向长度的10%，经过实际Newton重新查询。这些是合成姿态，不冒充网络实际输出。
- 原始QP终点与每个接受的网络姿态均保存原始Newton查询。原接触采用实际激活、约束分配与真实水平主表面筛选。

|---|---:|---:|---:|---:|---:|---|
| 原始姿态 | 0 | 8.9981 | 2.6564 | 0 | 0 | 未通过 |
| 固定QP教师 | — | 0 | 0 | 3.12471 | 19.06651 | 通过 |
| 直接姿态教师梯度 | 8 | 0 | 0 | 3.11251 | 18.99205 | 通过 |

网络教师误差平方损失最后为0.00205236，归一化误差范数0.0640681。
网络终态建立左脚接触并保留原左手/左膝；300个接受的网络步均保留原接触，contact/cell计划未改变。
终态接触保持残差0.13434cm，不是严格零。足部使用完整原始碰撞网格检查，未只看SDF采样点。
直接姿态路径并非处处无碰撞；网络路径Newton最大负距离也不单调下降。这里证明恢复终点有效，不证明每一步物理可执行。

## 方向解释

SDF环境项负梯度与完整QP方向的整体cosine为0.30613，左髋为-0.14392，左踝为0.65525。
SDF环境项覆盖全身，不包含接触保持/姿态项；QP目标也包含其他约束，因此方向不同不能单独证明SDF几何导数错误。

教师驱动网络的小步实际位移与教师方向整体cosine为0.42221，但左髋/左踝分别为0.99521/0.99957。
主要问题是不同自由度的幅值比例：网络最初仍偏重root，不能把整体cosine低直接解释为所有局部关节转反。
膝只有单个自由度，cosine为±1主要表示符号，必须同时看幅值；JSON保存各组范数及全部35维向量。

本实验表明：网络在这个样本上能通过正确教师损失学到恢复姿态，输出耦合会影响早期方向与速度，但不是不可克服的阻断。
这支持继续研究SDF场到运动学恢复方向的映射；尚未证明SDF→刚体twist→DLS能达到同样效果，也没有把QP教师写进正式训练。


| 向量对比 | 整体cosine | root | 左髋 | 左膝 | 左踝 |
|---|---:|---:|---:|---:|---:|
| SDF负梯度 / QP | 0.3061 | 0.8497 | -0.1439 | 1 | 0.6552 |
| SDF驱动网络位移 / SDF负梯度 | 0.5900 | 0.8268 | 0.9941 | 1 | 0.9919 |
| SDF驱动网络位移 / QP | 0.2467 | 0.7031 | -0.0503 | 1 | 0.7460 |
| 教师驱动网络位移 / QP | 0.4222 | 0.8654 | 0.9952 | 1 | 0.9996 |

同一SDF损失经过网络后，整体方向进一步偏离QP，但髋/踝局部方向与输入SDF梯度基本一致，
主要可见的是各自由度幅值比例变化，不能笼统说成网络把每个关节方向都扭反。

等归一化步长探针都保留原接触，但没有任何一个直接完成恢复：

| 等幅方向 | 足部全网格嵌入 cm | Newton最大负距离 cm | root位移 cm |
|---|---:|---:|---:|
| QP方向 | 8.18262 | 2.20740 | 0.31266 |
| SDF负梯度 | 6.76744 | 4.20365 | 0.59038 |
| 教师驱动网络方向 | 7.99712 | 3.46963 | 1.10600 |
| SDF驱动网络方向 | 7.73568 | 3.76172 | 1.11624 |

SDF在这个小步探针上的足部深度下降更多，但Newton最大负距离变差，说明不能只按一个穿透指标排名方向质量。

## 范围、复现与验证

网络初始重放不是逐位一致，最大分量差6.7592e-5，沿用上一轮明确的数值重放审计；所有网络方向以其自身初始前向为基准。
参考是网络原预测，不是前一帧；固定教师不随当前输出重新求解。
用户批准的本轮只做QP教师诊断，尚未实现constrained DLS。

入口：`python -m contact_solver.research.step14_loss_direction`，设置 `STEP14_QP_TEACHER=1` 和新的 `STEP14_FIELD_OUTPUT`；其余Newton worker参数同原静态实验。
`STEP14_TEACHER_STEPS` 默认300。未改原checkpoint，也未停止训练进程。
测试包含切空间往返、四元数符号等价、零/非零姿态gradcheck和教师负梯度方向验证；连同既有root代价和几何测试，共8项通过。

产物：`tmp/step14_qp_teacher_20260925_v2/`，含完整diagnostic、查询、CSV、收敛图与源码快照。
第一版 `v1` 只有教师驱动网络方向；`v2` 增补同一SDF损失驱动的网络方向，避免混淆两种损失的网络效应。
