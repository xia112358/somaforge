# 配套训练实验：paired_surface_v1

2026-09-13，经用户确认；保留旧权重与日志，不作为新的初始化。

## 共同数据

207 条、temporal_v2 切分、1–3 帧同表面断开共用防抖。
指纹 `45a649e34e46238957bb41c0b12b3ac67766710a7b236d64bac7af3343f4d35c`。
3320 个 predictor 样本；3527 个 infiller 示范片段。按整条轨迹的高度划分，
训练 h095/h100/h105、验证 h090、测试 h110，留出集不参加参数优化。

## Predictor

保留 joint_v2 网络、输入和输出结构，随机初始化训练 2000 epoch，不早停。
学习率、批量、姿态弱参考、关节限位与碰撞设计沿用前次。
新接触在真实有限顶面／无限地面区域上优化，使用记录中实际分配的
Newton includemargin；保持接触使用当前观测的材料点与当前锚点。
距离仅作可微代理，不定义接触真值。未知 margin 明确标记，不补常数。
示范锚点偏差降为诊断；角色标签仍来自下一示范事件，不是已经解决了
多种有效交互的专家监督。未增加终止头或事件编号。

## Infiller

同一个 direct_contact_infiller_v1 网络，一段式输出，首末 q 完全固定。
等待上述 predictor 完整结束后冻结 last.pt，重新初始化 infiller 一次训练，
4000 epoch，无墙钟提前结束；每 50 epoch 和最终轮完整评估。
先做完整单轮 benchmark，记录预估时间；不改变训练轮次以迎合时间估算。
frame_budget=2048，batch<=64，不缓存全语料 GPU batch，避免内存随语料翻倍。

语料包括全部示范片段和全部 3320 个 predictor 实际单次输出端点的片段。
两者分桶，分别报告指标，留出数据仍仅评估。
预测片段起点为示范当前状态，终点完全来自网络；无后续示范姿态输入。
预测时长按 50 Hz 采样，原时长和采样时长都保存；不投影／裁剪终点。
生成样本的 base 中间帧仅为端点三次插值弱参考，不冒充专家轨迹。

示范接触监督读取统一 Newton 时间线。预测片段的接触窗显式标为意图，
不填 task_contact_mask，不冒充 Newton 激活；未知 margin 单独报告。
保持接触约束当前材料点；新接触优化面内区域。接触朝向以弱示范参考保留，
预测片段不套用示范终点朝向。碰撞／平滑性／端点硬约束沿用已有实现。

## 限制与验收

预测片段目前覆盖的是示范起姿上的真实网络输出，不是递推／DAgger 起姿。
新语料不能自动保证递推完成；仍须用生成状态和 Newton 接触反馈测试。
预测终点若本身穿透或缺接触，infiller 硬端点不可能替它修复。训练与评估
不得把这部分归咎于 infiller，也不得把很小的最近距离当成正常支撑。
脚本只自动推进训练和离线几何评估，最终状态明确为“闭环／Newton 验证待做”。

启动监督入口：`tmp/run_paired_surface_training.py --predictor-pid <实际 PID>`。
进度：`tmp/paired_surface_v1/pipeline_status.json`。失败记录后停止推进，
不重启其他训练、不切换数据或悄悄减少预算。
