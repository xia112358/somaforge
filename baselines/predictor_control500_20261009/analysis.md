# control500 的首轮机制诊断

本轮固定 checkpoint，不构造优化器、不训练。使用 1.10 高度的 855 个相同示范起点样本，比较 source550 与 control500 的输出；对每个输出分别替换 root 平移、root 转动、29 个关节，调用现有权威 G1 FK 与完整形状距离计算。另检查原始示范终点，未改位姿或接触标签。

以下为每阶段 57 个样本的平均地形穿透，单位 mm。混合姿态列只恢复 source550 的 root 高度，保留 control500 的 XY、转动和关节；这不是可行姿态或接触通过结果。

| 阶段 | source550 | control500 | control500 恢复旧 root 高度 | root 高度变化 |
|---|---:|---:|---:|---:|
| 142→183 | 13.88 | 6.96 | 14.75 | +7.82 |
| 183→260 | 8.98 | 5.14 | 0.67 | −7.14 |
| 320→467 | 0.12 | 0.74 | 0.00 | −5.14 |
| 573→621 | 2.74 | 2.81 | 0.12 | −6.82 |
| 649→662 | 14.55 | 8.61 | 3.25 | −6.45 |

这些数据是静态完整形状距离，与正式指标使用的 Newton／完整形状最大深度上包络有微小数值差异。实际穿透与接触激活仍分开，不根据混合姿态距离推断支撑、接触保持或验收通过。

573→621 的左手平均穿透 2.74→1.58 mm，左脚 0.40→2.16 mm，右脚 0.11→1.01 mm。固定新转动和关节、仅恢复旧 root 高度后，分别约 0.065、0.051、0 mm。静态几何因此直接显示：该阶段 root 下移抵消了关节／姿态修正带来的部分间隙，且最深嵌入从手部转向足部。

这次 root 下移同时使姿态更接近示范：573→621 的 root 高度误差从高于示范 15.18 mm 降到 8.36 mm，全部 57 个样本都更接近；平均关节 RMSE 从 3.89° 降到 3.56°。原始示范终点的完整形状穿透只有约 0.00008 mm 的最大数值残量。该阶段不能归因于示范本身存在相同的严重嵌入。

但是不同阶段的 root 行为不一致：142→183 抬高 root 并减少手部嵌入；183→260 下移 root 后，高度误差反而全部离示范更远。因此目前不能把问题归结成一项统一的 root 高度偏置，也不能由此证明编码器坍缩或某个 loss 必然冲突。

已确认的是输出姿态内部的协调不足：更接近示范的部分变量，并不保证整个姿态的几何间隙同时改善。下一项需要沿原训练目标核对 root、关节输出分别收到的更新信号，判断这一组合来自哪些参数更新；本轮几何替换不回答训练梯度的唯一因果来源，不作为冻结 root、抬高 root、追加 loss 或投影补丁的依据。

原始分析产物：

- `tmp/baseline_control500_mechanism_20261009/reference_pose_comparison.json`：与精确原始示范终点的 root、关节及形状间隙对照。
