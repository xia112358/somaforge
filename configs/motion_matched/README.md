# Motion manifests

Only manifests whose motion files carry the canonical SomaForge
`robot_asset_json` identity may be added here. Previous manifests were moved to
`runtime/legacy_wrong_urdf/configs/motion_matched/`; they must not be used for
training or evaluation.

Regenerate source motions with the canonical G1 sphere-hand asset, then rebuild
Motion Edit force references and manifests before starting a new run.
